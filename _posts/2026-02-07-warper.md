I got creative for this weekend project after going pretty hard with [Systemique](./2026-01-03-systemique.md) over several days. With some inspiration from some random instagram reel on a collection of cool photoshop plugins, and my newly discovered capability to crap out code faster than I ever could before, I put together WarpeR.

[WarpeR](https://github.com/LGDan/WarpeR) is a browser based (you're going to see a pattern here) image effect processor for making glitch art. It runs chains of effects on images using a combination of matrix transforms, affines, rulesets on RGB values, and some other cool algos to make pretty patterns from any input image. It also includes a deterministic random pattern generator for exploring and sharing cool sequences of effects.

Select an image, and punch in a number from 0 to 100 and press enter. Then do it again! Did it too much? Press backspace to undo. Prefix any number with an `S` for a seeded pattern. Try `S3334` for example. Bit weird that.

[Have a go!](https://lgdan.github.io/WarpeR/)
