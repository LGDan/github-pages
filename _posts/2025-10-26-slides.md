Microsoft office is bloat. I don't want it on my computer. It's more attack surface, more crap to patch, and it takes a dump on my filesystem in more ways than one. It's proprietary, lacks HTML support, and runs all sorts of crap in the background.

If I want to do a presentation and get some slides going quickly, I'd quite like to do them in markdown, optionaly with some fancy rendering options, and present them via a browser.

Enter my project of this week, [slides.md](https://github.com/LGDan/slides.md). A minimalistic markdown slide presentation tool written in Go. Serve any markdown file as beautiful, themeable slides in your browser.

Themes are just CSS, and you run a single binary on your machine to serve up the current directory on a localhost web server. Arrow keys to flip between slides.

Simple and effective.
