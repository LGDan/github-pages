Object storage is mega versatile, simply because it has very well defined primatives and it doesn't do much more than it promises. The fact it doesn't try to do more is what makes it powerful.

You know what else has solid primatives? Block storage.

What if we mapped the primatives of block storage... to object storage? Have we just reinvented EBS?

[You tell me.](https://github.com/LGDan/iscsi-s3)

>Please please don't use this in production. The performance characteristics and reliability guarantees are WILDLY different for s3 vs block IO. You have been warned.
